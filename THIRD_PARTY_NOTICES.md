# Third-party notices and release scope

The Qwen/SAM integration builds on Qwen3-VL, Hugging Face Transformers, PEFT,
Segment Anything, SESAME and LISA/ReasonSeg. Dependencies are installed from
their original packages; pretrained weights are not redistributed. Existing
source attributions are retained. See `docs/DATA.md` for upstream projects.

This repository is a source-available research release. No new blanket license
is applied to third-party-derived integration code or numerical assets. Before
redistribution, commercial reuse or relicensing, establish the applicable
upstream permissions and the authors' intended license. GitHub visibility is
not a substitute for such a license.
